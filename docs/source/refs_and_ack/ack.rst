MODULO 3.0
----------

MODULO 3.0 was developed in collaboration with `Marek Belda
<https://github.com/BeldaMarek>`_, a visiting PhD researcher at the von Karman
Institute for Fluid Dynamics (VKI). His contributions to this release include
the fast spectral mPOD implementation, optional Fortran acceleration, VTK and
VTU input/output utilities, Tutorial 6, and the initial MODULO 3.0
documentation, originally proposed in `pull request #41
<https://github.com/mendezVKI/MODULO/pull/41>`_.
